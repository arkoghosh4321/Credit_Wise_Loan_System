# Credit_Wise_Loan_System

## Overview
A machine learning project focused on credit risk analysis and loan approval prediction using applicant-related financial and demographic features.

## Objectives
- Explore and analyze loan applicant data.
- Perform data cleaning and exploratory data analysis (EDA).
- Prepare relevant features for machine learning.
- Train and evaluate classification models for loan approval prediction.

## Project Workflow
1. Data collection and loading
2. Data preprocessing
3. Exploratory Data Analysis
4. Feature engineering and encoding
5. Model training
6. Model evaluation and comparison

## Project Structure
- `Credit_Wise_Loan_System.ipynb` — Data analysis, preprocessing, model training, and evaluation.
- `loan_data.csv` — Dataset, if redistribution is permitted.

## Tools and Libraries
Python, Jupyter Notebook, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn.

## How to Run
1. Clone or download this repository.
2. Install the required Python libraries.
3. Open the notebook in Jupyter Notebook.
4. Run the cells in sequence.

## Disclaimer
This project is for educational purposes only and is not intended to make real-world lending decisions.
